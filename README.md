# AppGrab

`AppGrab` — desktop-приложение на C++ для загрузки и просмотра событий по датам.

## Возможности

- выбор режима работы при запуске:
  - открыть существующий файл БД (`.db/.sqlite/.sqlite3`);
  - создать/использовать БД в выбранной папке;
- загрузка событий за выбранную дату;
- автоматическое сохранение загруженных из API данных в SQLite;
- табличный просмотр спарсенных записей.

## Стек

- C++17
- CMake (>= 3.16)
- wxWidgets
- SQLite3
- CPR (HTTP-клиент)
- nlohmann/json

## Структура проекта

```text
src/
  core/
    Database.*     # Работа с SQLite
    Parser.*       # Загрузка JSON по HTTP
  gui/
    App.*          # Жизненный цикл приложения
    DbSetupFrame.* # Окно выбора источника БД
    MainFrame.*    # Основной интерфейс
    AppDatabase.*  # Прослойка между GUI, БД и API
    AppState.h     # Текущее состояние выбора хранилища
```

## Сборка (Windows, CMake)

Пример через `vcpkg` (если зависимости установлены в vcpkg):

```powershell
cmake -A x64 -B ./build -DCMAKE_TOOLCHAIN_FILE=$env:VCPKG_ROOT/scripts/buildsystems/vcpkg.cmake
```
```powershell
cmake --build build
```

## Как использовать

1. Запустите приложение.
2. В стартовом окне выберите:
   - существующую БД
   - или папку для новой БД.
3. В главном окне выберите дату и нажмите **«Загрузить данные»**.
4. Если записей за дату нет в локальной БД, приложение запросит их с API и сохранит локально.
